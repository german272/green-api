# Telegram-чат на GREEN-API

Тестовое задание: веб-интерфейс для переписки в Telegram через [GREEN-API](https://green-api.com/telegram/docs/). Отправка и получение текстовых сообщений, список чатов, история переписки. React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

Нужен Node 20.19+ или 22.12+. Открыть http://localhost:5173, ввести `idInstance` и `apiTokenInstance` из [личного кабинета](https://console.green-api.com/).

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

## Настройка инстанса

У нового инстанса все уведомления выключены, и входящие сообщения в очередь не попадают. Приложение проверяет это после входа и предлагает включить получение кнопкой. Вручную: в настройках инстанса оставить `webhookUrl` пустым и включить «Получать уведомления о входящих сообщениях и файлах». Изменения применяются в течение пяти минут.

## Устройство

- `src/api` — клиент GREEN-API.
- `src/state` — редьюсер чатов: слияние истории, уведомлений и отправленных сообщений без дублей.
- `src/hooks` — загрузка чатов и истории, отправка, цикл `receiveNotification` → `deleteNotification`.
- `src/components` — экраны входа и чата.
- `src/utils` — форматирование времени.

Новый чат создаётся через `checkAccount`: для Telegram GREEN-API рекомендует отправлять сообщения по `chatId`, а не по номеру телефона.

## Ограничения

- Адрес API вычисляется из первых четырёх цифр `idInstance` (`4100…` → `https://4100.api.green-api.com`).
- Данные входа хранятся в `sessionStorage` до закрытия вкладки. Переписка локально не сохраняется, всё запрашивается у GREEN-API.
- Показываются только текстовые сообщения. История — последние 100 сообщений чата.
- Сообщения, отправленные с другого устройства, появятся в чате вживую, только если в настройках инстанса включены уведомления об исходящих; иначе — после перезагрузки, из истории.
